# sapstroi-site

Готовый сайт на Vite + React.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Telegram-заявки

В файле `src/main.jsx` замените:

```js
const TELEGRAM_BOT_TOKEN = 'PASTE_BOT_TOKEN_HERE';
const TELEGRAM_CHAT_ID = 'PASTE_OWNER_CHAT_ID_HERE';
```

на реальные данные бота и chat id владельца.

Для боевого сайта безопаснее отправлять заявки через backend, чтобы токен бота не был виден в браузере.

## Фотографии на сайте

Все изображения кладите в папку `public/images`. Сайт сам подхватит фото, если файл назван правильно.

1. `hero-main.png` — главное фото на первом экране справа.
2. `project-yard.png` — карточка “Двор частного дома” в блоке “Примеры объектов”.
3. `project-parking.png` — карточка “Парковка у коттеджа” в блоке “Примеры объектов”.
4. `project-paths.png` — карточка “Дорожки и зона отдыха” в блоке “Примеры объектов”.
5. `project-developer.png` — карточка “Территория застройщика” в блоке “Примеры объектов”.
6. `about-team.png` — резервное фото бригады или процесса работ, если позже добавлять отдельный блок о команде.

Если фото для карточки не добавлено, вместо него показывается чистая графическая заглушка без сетки.
